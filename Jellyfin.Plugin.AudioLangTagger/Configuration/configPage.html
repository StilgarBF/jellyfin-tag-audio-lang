Audio Language Tagger

Adds language tags to movies, episodes and series based on their audio tracks. Use the scheduled task "Tag audio languages" (Dashboard → Scheduled Tasks) to tag the existing library.

Only write what would change to the server log; do not modify any item.
Only tags listed in a language rule below are ever removed.

Existing library

New and changed items are tagged automatically. Items that are already in your library are only tagged when you run a scan. The scan uses the saved settings, so save first. Tip: enable "Dry run", save, scan, and check the server log before tagging for real.

Detection

Layers are checked from the most reliable to the least reliable.

Languages

Separate several values with commas. Words match as whole words, ignoring case; words of two letters or fewer (such as DE) match only in capitals.
